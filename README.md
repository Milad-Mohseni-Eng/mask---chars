# mask-chars

A tiny, educational Python example that demonstrates how to replace specific characters
in a string with a mask character (*). The script performs case-insensitive masking
for the characters p, o, and m.

## Why this repo?
This repository is intended as a simple demo for beginners learning:
- string iteration in Python
- case-insensitive comparisons
- writing small, testable functions

## Usage
Run the script from the project root:

```bash
python mask.py
# or
python -m mask_chars.mask "Python programming"
